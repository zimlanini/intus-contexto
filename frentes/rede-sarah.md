# Rede Sarah: CLM

Última revisão: 2026-10-06
Status: POC, contratação em andamento. Envolvimento: baixo hoje. Se o contrato sair, devo ser o PO e montar fluxos do produto com o time.

## O problema
As áreas de compras, jurídico, RH e outras não conversam entre si. O custo vai direto para o bolso da empresa: atrasos contratuais, dívidas com fornecedores, fornecedores inativos.

## O que o cliente quer
Sair de um SAP/4HANA engessado para uma solução de CLM (Contract Lifecycle Management).

## Divisão de papéis
- Fourtrust (parceira): tudo que envolve SAP.
- Intus: automações e integrações com IA. Só isso.

## Horizonte
Se o contrato sair para o ano que vem: um ano para construir o CLM com a Fourtrust, com o objetivo de garantir um contrato de mais 5 anos com a Rede Sarah. Roadmap só será desenhado quando avançar.
